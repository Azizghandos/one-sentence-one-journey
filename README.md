A complete story about a journey, told in exactly one sentence — written for the [One Sentence, One Journey](https://make.fun/c/u-gudril-cool-one-sentence-one-journey-410686ca) bounty on [make.fun](https://make.fun).

A traveller sets out for a lighthouse a day's walk away, loses the path to the tide, wades in with his shoes around his neck, and arrives to find a keeper who has waited sixty years for a visitor.

## Run

```sh
node main.ts
```

The program writes the one-sentence story to `/output/entry.txt` (set `OUTPUT_DIR` to write elsewhere, e.g. `OUTPUT_DIR=./out node main.ts`).
